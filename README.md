# DEAD SIGNAL : 서림고 — v0.6 / 5차 수정

기존 v0.5를 기반으로 한 멀티플레이 서버 및 화면 업데이트입니다.

## 배포
기존 GitHub 저장소에 압축파일의 `index.html`, `server.py`, `README.md`, `assets/` 및 설정 파일을 덮어쓰고 커밋하세요. Render 자동 배포가 켜져 있으면 같은 공개 URL에 반영됩니다. 서버 재시작 시 진행 중인 방은 초기화됩니다.

## 주요 변경
- PC 16:9 환경에 맞춰 3열 콕핏 레이아웃으로 압축. 좁은 화면은 기존 반응형 스크롤 레이아웃.
- 행동 텍스트 빠른 타이핑 효과.
- 층별 학교 구역 맵과 장소 이동 통합, 동료 위치 및 전투 구역 표시.
- 해당 장소에 감염자 또는 레이드 보스가 있을 때 조사·휴식·이동 봉쇄. 일반 전투는 공격 1회 후 반격 1회. 같은 장소의 동료는 공격에 참여 가능. 레이드에서도 공격 후 보스 반격.
- 조사 중 12% 확률로 소음 함정 발생. 방송실 장비/과학실 약품 선택 이벤트.
- 기절한 동료 업기, 내려놓기, 붕대로 치료하기. 업은 동료는 이동 시 함께 이동.
- 10분마다 다양한 교내 방송, 구조대 언급, 감염자 접근 이벤트.
- 10분마다 랜덤 구역 4곳에 NPC와 퀘스트 등장, 60초마다 전체 구역 물자 잔량 확인 후 30% 미만이면 재보급.
- 장비, 부상, 감염 부위 표시. 유대도에 따른 관계 호칭 및 유대도 85 이상일 때 고백/수락/거절.
- 게임 속 감염 부위 절단 선택지: 감염도 35 이상 + 소방 도끼/붕대/소독약 보유 시 감염도 0, 체력 감소, 영구 후유증. 현실의 의학적 조언이 아닌 픽션 게임 규칙입니다.

## 제한 사항
- 이 버전은 기존의 단일 공유 감염자 객체를 유지하므로 방 전체에 일반 감염자 한 마리만 활성화됩니다. 군인은 공지/무전 이벤트로 등장하며 독립 NPC AI는 아닙니다.
- 동료의 전투 참여는 같은 장소에서 직접 공격하는 방식입니다. 별도의 수락 모달은 아직 없습니다.
- 완전한 층별 건축 평면도가 아닌 층별 구역 배치도입니다.
- 관계/전투 상태는 서버 메모리에 저장되며 재시작 시 초기화됩니다.

## v0.8 알림 및 전투 합류
